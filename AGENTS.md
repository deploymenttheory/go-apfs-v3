# Naming

Name source files, tests, fixtures, identifiers, environment variables and CI
workflows after the filesystem structure or user capability they cover. Delivery
order and milestone numbering must never appear in those names or in capability
documentation. Test names should tell a reader what behavior is being verified.

Preserve captured native evidence and its original digests. Naming changes must
not rewrite original disk bytes, command logs, collector sources or observations.
Store historical text as compressed evidence when necessary and describe any
manifest naming projection explicitly.
